# Glowden — интернет-магазин обогревателей ПКН

Интернет-магазин обогревателей серии ПКН для румынской фирмы (ЕС). Статический сайт на HTML, CSS
и JavaScript без фреймворков и сборки: открывается прямо из файла (`index.html`), поэтому без
ES-модулей и без `fetch` локальных файлов — только обычные `<script>`. Запросы идут только
к Supabase (личный кабинет, заказы, настройки входа). Цены в евро.

- Репозиторий: https://github.com/andreibox44-hub/thermo (ветка `main`, публичный).
- Сайт опубликован на GitHub Pages: **https://andreibox44-hub.github.io/thermo/** — обновляется сам
  после каждого `git push` в `main`.

Название магазина — **Glowden** (glow — сияние, тепло; den — уютное логово): «тёплое гнёздышко».
Надпись логотипа: «Glow» тёплым градиентом + «den» (`texts.js → brand`). Ключи localStorage
по-прежнему `thermo.*` — не менять, иначе у покупателей пропадут корзина, избранное и вход.

## Правила

- **Все тексты интерфейса — только в `assets/js/texts.js`.** В HTML текста нет, только ключи
  (`data-i18n`, `data-i18n-placeholder`, `data-i18n-aria`); в JS — `App.t('ключ')`,
  `App.plural('ключ', n)` для множественного числа.
- **Товары — только в `assets/js/products.js`**, там только данные (без текстов). Названия товаров —
  в `texts.js → products`, описания собираются из шаблонов `texts.js → productTemplates[type]`.
  Общие характеристики задаются один раз: `HEATER_COMMON` (напольные, с вентиляцией, встраиваемые)
  и `CATEGORY_COMMON` (по категориям: тип прибора, сертификаты, ECO, общие свойства).
- **Страны доставки — только в `assets/js/countries.js`** (данные), их названия и подписи —
  в `texts.js → countries`.
- **Сайт пока на русском.** Потом переводим на румынский, английский, немецкий и итальянский:
  скопировать блок `ru` в `texts.js`, перевести, поменять `meta`. Переключатель языков в шапке
  появится сам, когда языков станет больше одного.
- **Ничего не выдумывать.** Неизвестные данные показываются как «уточняется». Цена `0` = «Цена
  уточняется», `area: null` = «Площадь уточняется». Характеристики, которые не заданы у товара,
  на странице не показываются. Справочные данные (города, индексы) — только из открытых
  источников (GeoNames), не по памяти.
- **После изменений загружать на GitHub** (`git add -A`, коммит, `git push` в `main`) — это сразу
  обновляет опубликованный сайт.
- **Кэш браузера.** CSS и JS подключаются с номером версии (сейчас `?v=20`). После изменения
  CSS/JS увеличить `?v=` во всех `*.html`; после замены фото — `IMAGE_VERSION` в `products.js`;
  после пересборки справочников — `GEO_VERSION` в `address.js`. Иначе браузер покажет старое.
- **Проверка в браузере** на ширине компьютера и телефона (~390 px): без ошибок в консоли и без
  горизонтальной прокрутки. На этом компьютере есть Edge и Node.js 24: скриншоты —
  `msedge --headless=new --screenshot`, сценарии (клики, вход, формы) — Edge с
  `--remote-debugging-port` и скрипт на Node через CDP (встроенный WebSocket). Тест входа через
  сервис — через локальный сервер (`python -m http.server`), с файла с диска он не работает.
- **База — настоящая.** Не создавать тестовые заказы (после удаления аккаунта они остаются).
  Тестовые аккаунты (`glowden.test.*@gmail.com`) удалять кнопкой «Удалить аккаунт» и проверять
  запросом, что их не осталось. Изменения схемы — миграцией и тем же текстом в `supabase/setup.sql`.

## Структура

```
index.html, catalog.html, product.html, cart.html, contacts.html   — страницы магазина
account.html                — личный кабинет (вход, регистрация, разделы)
terms.html, privacy.html, returns.html, delivery.html               — юридические страницы
assets/css/style.css        — все стили (токены цветов в :root, адаптив внизу файла)
assets/img/logo.svg         — значок логотипа Glowden: тёмный квадрат, контур домика в виде буквы G,
                              внутри светящийся уголёк; шапка, подвал, favicon
assets/img/products/<id>.webp — фото товаров (App.productImage; если image: null — рисунок heaterSVG)
assets/js/texts.js          — все тексты (window.TEXTS)
assets/js/products.js       — данные товаров (window.PRODUCTS)
assets/js/countries.js      — страны доставки (window.COUNTRIES): формат индекса, регион, справочник, включена ли
assets/js/app.js            — общее: переводы, формат цен, корзина и избранное (localStorage), страны,
                              шапка, подвал, карточка товара, фото/рисунки товаров, баннер cookies
assets/js/pages/*.js        — скрипт каждой страницы (home, catalog, product, cart, contacts, legal, account)
assets/js/config.js         — адрес и публичный ключ Supabase (если пусто — кабинет «скоро заработает»)
assets/js/auth.js           — App.auth: вход (почта, Google), регистрация, профиль, избранное, заказы,
                              удаление аккаунта
assets/js/address.js        — форма адреса доставки (App.address) для кабинета и корзины
assets/js/geo/<код>.js      — справочники городов и индексов по странам (GeoNames), RO, DE, CH, IT
assets/js/vendor/supabase.js — библиотека supabase-js 2.57.4 (лежит локально, без CDN — ради GDPR)
supabase/setup.sql          — таблицы profiles и orders, правила доступа (RLS), функции; внизу — обновления
tools/build_geo.py          — сборка справочников assets/js/geo из файлов GeoNames (инструкция внутри)
```

Каждая страница подключает по порядку: `texts.js`, `products.js`, `countries.js`, `app.js`, скрипт страницы.
Кабинет и корзина дополнительно подключают после `app.js`: `config.js`, `vendor/supabase.js`, `auth.js`, `address.js`.
Юридические страницы — один шаблон: `<body data-page="legal" data-doc="terms">` + `pages/legal.js`.

### Личный кабинет и заказы (Supabase)

- Проект Supabase `mjemowyqkroihrbbccux`: адрес и publishable key в `config.js`, «Confirm email»
  отключён. Где смотреть в панели: регистрации — Authentication → Users; профили и заказы —
  Table Editor → profiles / orders. Статус заказа меняется там же: `new`, `processing`, `shipped`,
  `done`, `cancelled` (подписи в `texts.js → account.orders.status`).
- База: `profiles` (имя, телефон, избранное и все поля адреса; создаётся триггером
  `handle_new_user` при регистрации, имя — из формы или `full_name` от Google) и `orders`
  (товары в `items` JSON, контакты, все поля адреса, оплата, `status`). RLS: каждый видит и
  меняет только своё; создать заказ можно только со статусом `new`. `delete_account()` удаляет
  пользователя: профиль удаляется, заказы остаются без привязки (`user_id = null`) для бухучёта.
- `account.html`: вход, регистрация, «Забыли пароль?», новый пароль по ссылке из письма. После
  входа — меню разделов (`account.html#раздел`): «Мои данные» (имя, телефон, почта, «Удалить
  аккаунт»), «Адрес доставки», «Избранное», «Мои заказы», «Выйти». На телефоне — полоска вкладок.
- Вход через Google: кнопка над формой входа/регистрации (`account.js → renderOAuth`,
  `auth.js → providers / signInWithProvider`; список сервисов — `OAUTH_ORDER`, только google).
  Сайт спрашивает у Supabase (`/auth/v1/settings`), включён ли Google, и только тогда показывает
  кнопку — **включён 2026-10-25** (Google Cloud: проект «Glowden», клиент Web application). Работает только по http/https (на GitHub Pages);
  с файла с диска — сообщение «заработает на хостинге». Отмена/ошибка входа — сообщение под формой.
- Адрес доставки — общая форма `assets/js/address.js` (App.address) в кабинете и корзине:
  страна → регион из списка → город (выпадающий список мест региона: сначала города, потом
  остальные по алфавиту; ввод сужает список; без региона — крупные города) → индекс (по нему
  подставляется город; предупреждение, если индекс другого места или его нет в справочнике) →
  улица, дом, квартира/офис, этаж, тип здания (дом / есть лифт / без лифта — товары до 43 кг),
  комментарий курьеру; по галочкам — получатель (другой человек) и счёт на фирму (название,
  налоговый номер с подписью под страну: CUI/CIF, USt-IdNr., UID, Partita IVA). Поля называются
  как столбцы `profiles` и `orders`.
- Справочники городов и индексов — `assets/js/geo/<код>.js` из почтовых файлов GeoNames
  (CC BY 4.0 — ссылка на geonames.org под формой обязательна): RO 13 851 место, DE 12 414,
  CH 4 081, IT 17 749. Грузятся только для выбранной страны (RO ~400 КБ). Собираются
  `tools/build_geo.py` (убирает служебные индексы фирм и абонентских ящиков, исправляет ş/ţ → ș/ț).
- Страны доставки (`countries.js`): включены Румыния (по умолчанию), Германия, Швейцария, Италия;
  подготовлены выключенными MD, AT, FR, ES, BG, HU, PL, NL, BE (включить — `enabled: true`).
  Список стран подставляется в «Доставку и оплату» (`{countries}`) и в кабинет.
- Корзина: если покупатель вошёл, форма заполняется из профиля (страна — только если в неё
  доставляем), заказ сохраняется в `orders` с настоящим номером. Без входа заказ
  демонстрационный (никуда не уходит).
- Политика конфиденциальности и баннер cookies перечисляют все данные: кабинет, адрес, получатель,
  фирма, избранное, вход через Google, Supabase как обработчик, сроки хранения.
