# Термо — интернет-магазин обогревателей ПКН

Интернет-магазин обогревателей серии ПКН для румынской фирмы (ЕС). Статический сайт на HTML, CSS
и JavaScript без фреймворков и сборки: открывается прямо из файла (`index.html`), поэтому без
ES-модулей и без `fetch` локальных файлов — только обычные `<script>`. Запросы идут только
к Supabase (личный кабинет и заказы). Цены в евро. Репозиторий:
https://github.com/andreibox44-hub/thermo (ветка `main`).

## Правила

- **Все тексты интерфейса — только в `assets/js/texts.js`.** В HTML текста нет, только ключи
  (`data-i18n`, `data-i18n-placeholder`, `data-i18n-aria`); в JS — `App.t('ключ')`,
  `App.plural('ключ', n)` для множественного числа.
- **Товары — только в `assets/js/products.js`**, там только данные (без текстов). Названия товаров —
  в `texts.js → products`, описания собираются из шаблонов `texts.js → productTemplates[type]`.
  Общие характеристики задаются один раз: `HEATER_COMMON` (напольные, с вентиляцией, встраиваемые)
  и `CATEGORY_COMMON` (по категориям: тип прибора, сертификаты).
- **Сайт пока на русском.** Потом переводим на румынский, английский, немецкий и итальянский:
  скопировать блок `ru` в `texts.js`, перевести, поменять `meta`. Переключатель языков в шапке
  появится сам, когда языков станет больше одного.
- **Ничего не выдумывать.** Неизвестные данные (цены, площадь, данные фирмы, контакты) показываются
  как «уточняется» / «Цена уточняется». Цена `0` = «Цена уточняется», `area: null` = «Площадь
  уточняется». Характеристики, которые не заданы у товара, на странице не показываются.
- **После изменений загружать на GitHub** (`git add -A`, коммит, `git push` в `main`).
- **Кэш браузера.** CSS и JS подключаются с номером версии (`style.css?v=8`). После изменения
  CSS/JS увеличить `?v=` во всех `*.html`; после замены фото — `IMAGE_VERSION` в `products.js`.
  Иначе браузер покажет старую версию.
- После правок проверять сайт в браузере на ширине компьютера и телефона (~390 px): без ошибок
  в консоли и без горизонтальной прокрутки.

## Структура

```
index.html, catalog.html, product.html, cart.html, contacts.html   — страницы магазина
account.html                — личный кабинет (вход, регистрация, мои данные, мои заказы)
terms.html, privacy.html, returns.html, delivery.html               — юридические страницы
assets/css/style.css        — все стили (токены цветов в :root, адаптив внизу файла)
assets/img/logo.svg         — значок логотипа (зелёный квадрат, красный огонёк): шапка, подвал, favicon
assets/img/products/<id>.webp — фото товаров (App.productImage; если image: null — рисунок heaterSVG)
assets/js/texts.js          — все тексты (window.TEXTS)
assets/js/products.js       — данные товаров (window.PRODUCTS)
assets/js/app.js            — общее: переводы, формат цен, корзина (localStorage), шапка, подвал,
                              карточка товара, картинки товаров в SVG (heaterSVG), баннер cookies
assets/js/pages/*.js        — скрипт каждой страницы (home, catalog, product, cart, contacts, legal, account)
assets/js/config.js         — адрес и публичный ключ Supabase (если пусто — кабинет «скоро заработает»)
assets/js/auth.js           — App.auth: вход, регистрация, профиль, заказы, удаление аккаунта
assets/js/vendor/supabase.js — библиотека supabase-js 2.57.4 (лежит локально, без CDN — ради GDPR)
supabase/setup.sql          — таблицы profiles и orders, правила доступа (RLS), функция delete_account
```

Каждая страница подключает по порядку: `texts.js`, `products.js`, `app.js`, скрипт страницы.
Кабинет и корзина дополнительно подключают после `app.js`: `config.js`, `vendor/supabase.js`, `auth.js`.
Юридические страницы — один шаблон: `<body data-page="legal" data-doc="terms">` + `pages/legal.js`.

## Что сделано

- Главная, каталог (поиск, сортировка, фильтры по категории, площади помещения и мощности),
  карточка товара, корзина с формой заказа, контакты с формой и частыми вопросами.
- Категории: напольные (4), с вентиляцией (2), встраиваемые в пол (3), алюминиевые радиаторы (7),
  аксессуары (1). У всех цена 0 («Цена уточняется»).
- Фото товаров вырезаны из рекламных карточек производителя (жёлтый фон убран). Алюминиевые
  радиаторы собраны из фото 6-секционного (на остальных карточках секции закрыты значками),
  число секций — как у модели. Характеристики — текстом на странице товара.
- Зелёная метка ECO на фото у всех обогревателей (`eco: true` в `CATEGORY_COMMON`), справа вверху;
  слева — «Сертификат CE». Обе выводит `certBadges` в `app.js`. (Значок с листьями с карточек
  пробовали — поверх фото выглядит, будто обогреватель «откусан».)
- Данные алюминиевых радиаторов — с карточек: площадь, объём, потребление, габариты, вес;
  общее для категории: алюминиевые секции, электронное управление со встроенным терморегулятором,
  220 В, 50 Гц, однофазная сеть, срок службы 30–50 лет, потолок до 2,8 м (без Wi‑Fi).
  У всех обогревателей указан объём помещения (`volume`).
- Главная: в большой карточке первого экрана каждые 3,2 с сменяются модели с подписью и ссылкой
  на товар (список `SHOWCASE` в `pages/home.js`); пауза при наведении, без анимации при «уменьшить движение».
- Сертификат CE у напольных, с вентиляцией и алюминиевых; тип прибора «обогреватель на
  конденсированном паре» у всех, кроме аксессуаров. Предупреждение у ПКН-6+В (отдельная линия, 27,3 А).
- Цены в евро (`1 234,50 €`), бесплатной доставки нет — стоимость сообщает менеджер.
- Контакты — заглушки для Румынии (`+40 XXX XXX XXX`, info@example.com, адрес «уточняется»).
- Юридические страницы (условия продажи, GDPR, возврат 14 дней с формой отказа, доставка и оплата),
  данные продавца в `texts.js → legal.seller`.
- Подвал: ссылки на документы, значки ANPC (SAL) и SOL, «Настройки cookies».
- Баннер cookies: Google Fonts загружаются только после «Принять все».

### Личный кабинет и заказы (Supabase)

- Проект Supabase `mjemowyqkroihrbbccux` подключён: адрес и publishable key в `config.js`,
  `supabase/setup.sql` выполнен, «Confirm email» отключён (сайт ещё не на хостинге).
- База: `profiles` (имя, телефон, город, адрес; создаётся триггером при регистрации) и `orders`
  (товары в `items` JSON, контакты, оплата, `status`). RLS: каждый видит и меняет только своё;
  создать заказ можно только со статусом `new`. `delete_account()` удаляет пользователя:
  профиль удаляется, заказы остаются без привязки (`user_id = null`) для бухучёта.
- `account.html`: вход, регистрация, «Забыли пароль?» и новый пароль по ссылке из письма,
  «Мои данные», «Мои заказы» (номер, дата, статус, товары), «Выйти», «Удалить аккаунт».
  Значок кабинета в шапке рядом с корзиной.
- Корзина: если покупатель вошёл, форма заполняется из профиля, заказ сохраняется в `orders`
  и номер заказа — настоящий. Без входа заказ по-прежнему демонстрационный (никуда не уходит).
- Сессия входа хранится в localStorage (`thermo.auth`); тексты баннера cookies и политики
  конфиденциальности дополнены (данные кабинета, Supabase как обработчик, сроки хранения).
- Где смотреть в панели Supabase: регистрации — Authentication → Users; профили —
  Table Editor → profiles; заказы — Table Editor → orders. Статус заказа меняется там же:
  `new`, `processing`, `shipped`, `done`, `cancelled` (подписи в `texts.js → account.orders.status`).
- Проверка: в настоящей базе не создавать тестовые заказы (после удаления аккаунта они остаются);
  тестовые аккаунты удалять кнопкой «Удалить аккаунт».

## Что осталось сделать

- Данные фирмы, адрес, телефон, часы работы — вместо заглушек «уточняется».
- Цены товаров; объём и потребление ПКН-3-1.6-16 (карточки производителя нет; площадь 20 м² — от заказчика).
- Порядок габаритов: на карточках подпись «L/A/P», но у радиаторов первое число — высота (570).
- Юридические тексты проверить у юриста; заменить нарисованные значки ANPC/SOL на официальные
  пиктограммы ANPC; уточнить, нужна ли ещё ссылка SOL (платформа ODR ЕС закрыта в 2025 г.).
- Переводы: румынский, английский, немецкий, итальянский.
- Настоящая отправка заказов без входа и сообщений из формы «Напишите нам» (сейчас никуда не уходят;
  сохраняются только заказы из личного кабинета). Уведомлять менеджера о новых заказах (почта).
- Настоящие фото товаров в хорошем качестве (сейчас вырезаны из карточек, ~300 px; фото
  ПКН-3-1.6-16 и алюминиевых собраны из одного снимка). Заменить файлы в `assets/img/products/`.
- Хостинг сайта.
- Supabase после хостинга: указать адрес сайта в Authentication → URL Configuration (иначе ссылки
  из писем «Забыли пароль?» не откроются), подключить свою почту (SMTP — встроенная отправляет
  всего несколько писем в час) и снова включить «Confirm email».
- Узнать регион проекта Supabase (Project Settings → General) и вписать его в политику
  конфиденциальности (`texts.js → legal.docs.privacy`, раздел 5, сейчас «уточняется»).
- Оформить заказ из кабинета на настоящем проекте один раз вручную (проверено только на заглушке).
