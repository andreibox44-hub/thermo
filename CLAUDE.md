# Термо — интернет-магазин обогревателей ПКН

Интернет-магазин обогревателей серии ПКН для румынской фирмы (ЕС). Статический сайт на HTML, CSS
и JavaScript без фреймворков и сборки: открывается прямо из файла (`index.html`), поэтому без
ES-модулей и `fetch` — только обычные `<script>`. Цены в евро. Репозиторий:
https://github.com/andreibox44-hub/thermo (ветка `main`).

## Правила

- **Все тексты интерфейса — только в `assets/js/texts.js`.** В HTML текста нет, только ключи
  (`data-i18n`, `data-i18n-placeholder`, `data-i18n-aria`); в JS — `App.t('ключ')`,
  `App.plural('ключ', n)` для множественного числа.
- **Товары — только в `assets/js/products.js`**, там только данные (без текстов). Названия товаров —
  в `texts.js → products`, описания собираются из шаблонов `texts.js → productTemplates[type]`.
  Общие характеристики задаются один раз: `HEATER_COMMON` (напольные, с вентиляцией, встраиваемые)
  и `CATEGORY_COMMON` (по категориям: тип прибора, сертификаты).
- **Сайт пока на русском.** Потом переводим на румынский, английский, немецкий и итальянский:
  скопировать блок `ru` в `texts.js`, перевести, поменять `meta`. Переключатель языков в шапке
  появится сам, когда языков станет больше одного.
- **Ничего не выдумывать.** Неизвестные данные (цены, площадь, данные фирмы, контакты) показываются
  как «уточняется» / «Цена уточняется». Цена `0` = «Цена уточняется», `area: null` = «Площадь
  уточняется». Характеристики, которые не заданы у товара, на странице не показываются.
- **После изменений загружать на GitHub** (`git add -A`, коммит, `git push` в `main`).
- После правок проверять сайт в браузере на ширине компьютера и телефона (~390 px): без ошибок
  в консоли и без горизонтальной прокрутки.

## Структура

```
index.html, catalog.html, product.html, cart.html, contacts.html   — страницы магазина
terms.html, privacy.html, returns.html, delivery.html               — юридические страницы
assets/css/style.css        — все стили (токены цветов в :root, адаптив внизу файла)
assets/img/logo.svg         — значок логотипа (зелёный квадрат, красный огонёк): шапка, подвал, favicon
assets/js/texts.js          — все тексты (window.TEXTS)
assets/js/products.js       — данные товаров (window.PRODUCTS)
assets/js/app.js            — общее: переводы, формат цен, корзина (localStorage), шапка, подвал,
                              карточка товара, картинки товаров в SVG (heaterSVG), баннер cookies
assets/js/pages/*.js        — скрипт каждой страницы (home, catalog, product, cart, contacts, legal)
```

Каждая страница подключает по порядку: `texts.js`, `products.js`, `app.js`, скрипт страницы.
Юридические страницы — один шаблон: `<body data-page="legal" data-doc="terms">` + `pages/legal.js`.

## Что сделано

- Главная, каталог (поиск, сортировка, фильтры по категории, площади помещения и мощности),
  карточка товара, корзина с формой заказа, контакты с формой и частыми вопросами.
- Категории: напольные (4), с вентиляцией (2), встраиваемые в пол (3), алюминиевые радиаторы (7),
  аксессуары (1). У всех цена 0 («Цена уточняется»).
- Сертификат CE у напольных, с вентиляцией и алюминиевых; тип прибора «обогреватель на
  конденсированном паре» у всех, кроме аксессуаров. Предупреждение у ПКН-6+В (отдельная линия, 27,3 А).
- Цены в евро (`1 234,50 €`), бесплатной доставки нет — стоимость сообщает менеджер.
- Контакты — заглушки для Румынии (`+40 XXX XXX XXX`, info@example.com, адрес «уточняется»).
- Юридические страницы (условия продажи, GDPR, возврат 14 дней с формой отказа, доставка и оплата),
  данные продавца в `texts.js → legal.seller`.
- Подвал: ссылки на документы, значки ANPC (SAL) и SOL, «Настройки cookies».
- Баннер cookies: Google Fonts загружаются только после «Принять все».

## Что осталось сделать

- Данные фирмы, адрес, телефон, часы работы — вместо заглушек «уточняется».
- Цены товаров; площадь обогрева, габариты и вес алюминиевых радиаторов (кроме ПКН-3-1.6-16).
- Уточнить, относятся ли к алюминиевым радиаторам общие свойства серии (корпус, Wi‑Fi, 220 В,
  срок службы, высота потолка); порядок габаритов (что ширина, что высота).
- Юридические тексты проверить у юриста; заменить нарисованные значки ANPC/SOL на официальные
  пиктограммы ANPC; уточнить, нужна ли ещё ссылка SOL (платформа ODR ЕС закрыта в 2025 г.).
- Переводы: румынский, английский, немецкий, итальянский.
- Настоящая отправка заказов и сообщений (сейчас формы демонстрационные, данные никуда не уходят).
- Фотографии товаров вместо SVG-картинок (`heaterSVG` в `app.js`).
- Хостинг сайта.
